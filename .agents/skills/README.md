# Project Skills

This directory is the project-local skills home for Codex-style workflows.

Rules:

- Keep each skill in its own folder.
- Keep `SKILL.md` and supporting files together.
- Copy important Claude skills here from `.claude/skills/` if that directory is added later.
- Do not put project skills in `.codex/skills/`; that location is for user/global Codex skill installs, not repo-local handoff.
